# FreeCut Workspace Contract Specification (Spike S0.2)

- **Date:** 2026-10-24
- **Branch:** `spike/s0` (Engine) / `spike/s0-handoff` (Studio)
- **Target Schema Version:** FreeCut Project Schema v15, Workspace Schema v2.0
- **Scope:** Complete specification of the filesystem contract between TeamTrau Python Engine and TeamTrau Studio (FreeCut fork).

---

## 1. Directory Structure Overview

The contract follows FreeCut's workspace layout defined in `src/infrastructure/storage/workspace-fs/paths.ts` (lines 11-53):

```text
{workspace}/
├── .freecut-workspace.json          # Workspace marker & schema version
├── index.json                       # Fast project list
├── projects/
│   └── {projectId}/
│       ├── project.json             # Project descriptor (schema v15)
│       └── media-links.json         # Project ↔ Media associations
├── media/
│   └── {mediaId}/
│       ├── metadata.json            # Media metadata (storageType: "handle" in LINK mode)
│       ├── {sanitizedFileName}.mp4  # Hard-linked source media (zero copy on disk)
│       └── cache/
│           └── ai/
│               └── teamtrau.json    # TeamTrau AI analysis envelope (role, golden, score)
└── content/
    └── proxies/                     # (Reserved for S0.3 / Phase 1)
```
